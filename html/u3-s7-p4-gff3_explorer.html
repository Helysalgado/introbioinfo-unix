Síntesis Final

Anatomía Consolidada del Estándar GFF3

Cada campo responde a una pregunta biológica bien definida:

1. seqid

¿Sobre qué secuencia de referencia se definen estas coordenadas?

2. source

¿Qué software, base de datos o evidencia produjo la anotación?

3. type

¿Qué tipo ontológico de feature describe la línea (gene, CDS, mRNA)?

4 & 5. start / end

¿Entre qué coordenadas 1-based e inclusivas se ubica?

6. score

Puntuación numérica de predicción. . = Ausencia/No aplica (¡No es cero!).

7. strand

Hebra relativa a la referencia (+ o -).

8. phase

Fase de lectura para features CDS (0, 1, 2). Para gene vale .

9. attributes

Pares clave-valor (ID, Name, Parent) separados por ;

Conexión de Formatos: GFF3 ↔ FASTA ↔ GenBank

Un archivo GFF3 contiene coordenadas y metadatos, pero no sustituye la secuencia de nucleótidos del FASTA. Para extraer la secuencia física de una feature anotada en GFF3, debes disponer del archivo FASTA con el mismo ensamblado de referencia (seqid=NC_000913.3).
