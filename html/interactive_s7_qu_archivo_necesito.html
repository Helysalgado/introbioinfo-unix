🔄 Algoritmo de Decisión Rápida

¿Solo secuencia pura?
→ Usar FASTA (.fasta, .fa)
¿Solo coordenadas/exones/CDS?
→ Usar GFF3 (.gff3, .gff)
¿Secuencia + Metadatos + Anotación?
→ Usar GenBank (.gb, .gbk)
¿Extracción de secuencias anotadas?
→ Combinar GFF3 + FASTA

Regla de Oro: Primero identifica la evidencia requerida; después selecciona la extensión del archivo.
