Práctica 3: Orientación, Consulta de Ayuda y Control

Estrategias para explorar directorios, leer documentación y controlar procesos de forma segura.

Pendiente

1. Orientarme (Exploración de archivos)

remoto$ pwd
remoto$ ls
remoto$ ls -l
remoto$ ls -lh
Atención pedagógica

El comando ls -lh confirma la presencia, el nombre y el tamaño visible del archivo, pero NO demuestra su integridad ni su contenido intacto.

2. Consultar (Uso de man)

Ejecuta en el servidor remoto: man ls. Busca la opción -h utilizando las flechas de navegación y sal presionando la tecla q.

3. Controlar (Autocompletado, Historial e Interrupción)

Prueba en tu terminal real: usar la tecla Tab para autocompletar, la flecha ↑ y el comando history, y el comando sleep 30 seguido inmediatamente de Ctrl-C.

Práctica 5: Verificación de Integridad con Hashes SHA-256

Evidencia antes de confianza: Ver un archivo ≠ demostrar que llegó intacto.

Pendiente
Regla de oro de la Bioinformática

Un archivo dañado, incompleto o alterado durante la transferencia conducirá a análisis erróneos. El comando ls -lh confirma la existencia del archivo, pero solo la verificación criptográfica mediante SHA-256 demuestra integridad.

# macOS (Terminal local):
shasum -a 256 pacientes.md
shasum -a 256 pacientes-metadatos.md

# Linux / WSL / Git Bash (Local) y Servidor Remoto (Linux):
sha256sum pacientes.md
sha256sum pacientes-metadatos.md

# PowerShell (Windows Local):
Get-FileHash .\pacientes.md -Algorithm SHA256
Get-FileHash .\pacientes-metadatos.md -Algorithm SHA256
