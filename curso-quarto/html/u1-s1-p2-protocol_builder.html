Protocol Builder

De una estrategia científica a un documento reproducible en Markdown

Meta de la sesión: Construir la base de tu protocolo.md utilizando Markdown estructurado y diagramas Mermaid.

Ya tienes una pregunta y una estrategia.

Ahora convierte ese razonamiento en un documento reproducible en formato Markdown. Usa la sintaxis estructural mínima y diagramas Mermaid para darle claridad visual a tu protocolo.

Misión 1

Paso 1 de 4

Guía rápida Markdown: # Título (H1) ## Sección (H2) ### Subsección (H3) - Ítem (Lista) **texto** (Negrita) `archivo` (Código inline)

Documentación y Metadatos

La documentación y los metadatos (fechas, versiones de datos, bitácoras) atraviesan todo el proceso. No pertenecen a una sola sección aislada, sino que garantizan la reproducibilidad científica continua.

Misión 3

Del texto al diagrama: Mermaid en Markdown

Paso 3 de 4

Markdown estructura el texto; Mermaid genera diagramas de flujo directamente desde bloques de código dentro del propio documento.

// Sintaxis Mermaid en Markdown:
```mermaid
flowchart LR
    A[Pregunta] --> B[Evidencia]
    B --> C[Datos]
```
Elementos del diagrama:

• flowchart LR: Diagrama de flujo de izquierda a derecha (Left → Right).

• A, B, C: Identificadores únicos de nodo.

• [Texto visible]: Etiqueta dentro del nodo.

• -->: Conector con flecha orientada.
