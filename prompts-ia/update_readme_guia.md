# Actualización del README y de la guía de generación del curso

Quiero que revises y modifiques estos dos documentos del proyecto:

- README.md
- guia-generacion-unidad.md

NO quiero una reescritura.

NO quiero cambiar la filosofía general del curso.

Quiero incorporar las lecciones aprendidas durante el desarrollo de la Unidad 4 para que todas las unidades futuras nazcan con este mismo estándar.

Piensa como un editor académico que está refinando un estándar institucional.

---

# Objetivo

Actualizar ambos documentos para que reflejen explícitamente la filosofía didáctica que fue consolidándose en las sesiones S10 y S11.

Las modificaciones deben ser pequeñas, coherentes y reutilizables.

No quiero reglas específicas para cut, grep o GFF3.

Quiero principios generales.

---

# 1. Reforzar la identidad del curso

Agregar explícitamente que este NO es un curso de Unix.

Tampoco es un curso de comandos.

Es un curso de Introducción a la Bioinformática donde las herramientas computacionales se presentan únicamente como medios para responder preguntas biológicas.

Incorporar un principio como:

> Las preguntas biológicas permanecen; las estrategias de análisis evolucionan.

---

# 2. Incorporar el principio de "capacidad analítica creciente"

Agregar un principio didáctico explícito.

Las sesiones no introducen ejercicios completamente nuevos.

Las mismas preguntas biológicas pueden revisitarse varias veces conforme aparecen herramientas nuevas.

Cada nueva sesión debe permitir producir una respuesta:

- más precisa;
- mejor fundamentada;
- más reproducible;
- con evidencia de mayor calidad.

No repetir ejercicios.

Refinar respuestas anteriores.

---

# 3. Expresar que las herramientas aparecen por necesidad

Agregar un principio metodológico.

Nunca introducir un comando únicamente porque "toca verlo".

Cada herramienta debe aparecer porque resuelve una limitación detectada en la sesión anterior.

El alumno debe sentir que la herramienta responde a un problema real.

No a un orden arbitrario del temario.

---

# 4. Reforzar la continuidad narrativa entre sesiones

Agregar una recomendación editorial.

Cada sesión debería responder tres preguntas:

- ¿Qué problema resolvió la sesión anterior?
- ¿Qué mejora aporta esta sesión?
- ¿Qué limitación permanece abierta para la siguiente?

No es obligatorio usar exactamente esas preguntas.

Pero la progresión debe sentirse natural.

---

# 5. Consolidar el protocolo como eje del curso

Actualmente el protocolo ya aparece como producto acumulativo.

Quiero reforzar que:

el protocolo no es un entregable.

Es el registro del razonamiento científico.

Debe crecer sesión tras sesión.

Cada sesión debe modificar únicamente la parte correspondiente.

Nunca reiniciarse.

---

# 6. Incorporar el principio "dato ≠ operación"

Agregarlo como principio transversal.

Toda práctica debería ayudar al estudiante a distinguir:

- la pregunta biológica;
- el dato necesario;
- la operación necesaria;
- la herramienta adecuada.

Mantener siempre ese orden.

Nunca comenzar por el comando.

---

# 7. Reforzar el lenguaje del curso

Agregar una recomendación de estilo.

Siempre que sea posible, favorecer expresiones como:

- construir evidencia;
- localizar el dato;
- refinar una respuesta;
- contrastar resultados;
- justificar una interpretación;
- fortalecer una conclusión;
- documentar la estrategia.

Evitar que el texto se centre únicamente en "usar un comando".

---

# 8. Prácticas progresivas

Agregar explícitamente que las prácticas deben construirse como una escalera.

Cada práctica debería apoyarse en una anterior.

No diseñar actividades aisladas.

Cuando sea posible:

- recuperar resultados previos;
- compararlos;
- refinarlos;
- documentar qué mejoró.

---

# 9. Identidad de las sesiones

Agregar una recomendación editorial.

Las sesiones deberían terminar dejando una limitación abierta.

No como cliffhanger artificial.

Sino como consecuencia natural del análisis.

La sesión siguiente debe surgir como respuesta a esa limitación.

---

# 10. Organización visual

Agregar recomendaciones para mejorar la lectura.

Cuando una práctica tenga muchos pasos:

- dividirla mediante subtítulos breves;
- facilitar su navegación durante el taller;
- evitar bloques de texto demasiado largos.

No aumentar el contenido.

Mejorar únicamente la experiencia de lectura.

---

# 11. Uso de callouts

Agregar una nota editorial.

Los callouts:

- IMPORTANTE
- TIP
- ADVERTENCIA
- NOTA

deben utilizarse con moderación.

No convertir cada observación en un callout.

Conservar su impacto visual.

---

# 12. Revisión transversal

Agregar una recomendación para futuras unidades.

Cuando una unidad esté terminada, realizar una revisión horizontal para comprobar:

- consistencia terminológica;
- continuidad narrativa;
- longitud de las prácticas;
- estilo de las figuras;
- referencias cruzadas;
- equilibrio en el uso de callouts;
- evolución del protocolo.

---
