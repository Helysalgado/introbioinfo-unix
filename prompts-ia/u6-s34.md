# Gran pregunta de la sesión

Toda la sesión debe responder una única pregunta.

> **Tengo una secuencia desconocida. ¿Qué hipótesis biológica puedo construir y cómo puedo defenderla utilizando evidencia reproducible?**

Toda la sesión debe girar alrededor de esa pregunta.

# Filosofía

No evaluar si el estudiante obtiene "la respuesta correcta".

Evaluar si:

- construye evidencia;
- reconoce incertidumbre;
- justifica decisiones;
- distingue hechos de inferencias;
- identifica limitaciones;
- propone experimentos adicionales.

La Bioinformática no produce certezas automáticas.

Produce evidencia para construir hipótesis.

---

# Propósito

Que el estudiante integre todo el flujo de trabajo de la unidad para elaborar una interpretación científica reproducible y defendible.

---

# Competencias que integra

La sesión debe exigir que el estudiante sea capaz de:

✓ formular una pregunta biológica;

✓ seleccionar una estrategia de búsqueda;

✓ justificar la base de datos utilizada;

✓ interpretar alineamientos;

✓ comparar varios hits;

✓ evaluar identidad, cobertura, score y E-value;

✓ reconocer los límites de la inferencia;

✓ distinguir similitud y homología;

✓ argumentar una conclusión;

✓ documentar todo el proceso;

✓ evaluar críticamente una respuesta generada por IA.

---

# Situación problema

El estudiante recibe una secuencia (o un pequeño conjunto de secuencias) cuya función o relación evolutiva no se indica explícitamente.

Debe investigar:

- qué proteínas similares existen;
- qué evidencia aportan;
- cuál parece el mejor candidato;
- qué puede afirmarse;
- qué todavía no puede concluirse.

No debe existir una única respuesta posible.

# IA

La IA debe desempeñar un papel central.

Actividad principal.

La IA entrega un informe aparentemente correcto.

El estudiante debe:

- verificar todas las afirmaciones;
- distinguir hechos e inferencias;
- detectar exageraciones;
- identificar afirmaciones sin evidencia;
- corregir el informe;
- justificar cada corrección.

La conclusión debe ser:

La IA ayuda a construir hipótesis.

El investigador decide si están sustentadas.

# Reflexión final

Cerrar la unidad con una reflexión explícita.

La Bioinformática no consiste en ejecutar BLAST.

Ni en obtener el primer hit.

Consiste en evaluar críticamente evidencia para construir hipótesis biológicas que puedan sostenerse frente al escrutinio científico.

En la era de la inteligencia artificial, esta competencia adquiere aún mayor importancia.

La IA puede generar explicaciones.

La evidencia decide cuáles sobreviven.
