# Rol de S13 dentro de la Unidad 4

Esta sesión marca el cierre del primer gran bloque del análisis del genoma.

Hasta ahora el estudiante aprendió a:

- observar archivos;
- localizar información;
- seleccionar registros;
- comprender la estructura del GFF3.

Ahora aprenderá algo diferente.

Construirá el **primer inventario descriptivo del genoma**.

No se trata únicamente de contar.

Se trata de responder:

> ¿Qué contiene realmente este genoma?

# Propósito (NO modificar)

Pasar del conteo puntual al inventario exhaustivo: obtener el catálogo completo de categorías presentes en la anotación y su frecuencia, sin conocerlas de antemano.

Hasta ahora el estudiante formulaba preguntas específicas.

Por ejemplo:

Ahora aprenderá una estrategia completamente distinta.

En lugar de preguntar por un valor concreto,

# Filosofía para introducir sort y uniq

Las herramientas NO aparecen porque "toca aprenderlas".

Aparecen porque el estudiante descubre una limitación.

Por ejemplo.

Con grep puede responder:

¿Cuántos genes?

Pero todavía necesita formular cada pregunta manualmente.

Ahora quiere responder:

¿Qué contiene TODO el archivo?

Entonces aparecen naturalmente:

sort

↓

uniq

↓

uniq -c

El estudiante debe sentir que las herramientas responden una necesidad real.

# Advertencia conceptual importante

Debe quedar muy claro que:

Número de registros

≠

Número de objetos biológicos.

Por ejemplo:

Una CDS no representa necesariamente un gen diferente.

Una anotación puede generar varios registros.

El estudiante debe aprender que contar registros no siempre significa contar entidades biológicas.

Este probablemente sea el concepto más importante de toda la sesión.

Dedicarle un recuadro IMPORTANTE.

# Validación

La pregunta:

¿Cuántos replicones tiene el genoma?

Debe responderse utilizando tres estrategias independientes.

Por ejemplo:

- FASTA
- GFF3
- directivas sequence-region

El objetivo no es repetir comandos.

El objetivo es mostrar cómo varias evidencias independientes fortalecen una conclusión.

No llamar a esto redundancia.

Llamarlo validación.
