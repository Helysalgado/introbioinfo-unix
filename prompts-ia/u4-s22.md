# 2. Contexto del curso

Este **no es un curso de Unix**.

Tampoco es un curso general de programación en `awk`.

Es un curso de Bioinformática cuyo objetivo es formar estudiantes capaces de:

* formular preguntas biológicas;
* identificar qué datos permiten responderlas;
* elegir una operación analítica adecuada;
* ejecutar esa operación reproduciblemente;
* verificar sus resultados;
* interpretar la evidencia;
* declarar límites y discrepancias.

Unix y `awk` son únicamente instrumentos para expresar y resolver preguntas biológicas.

Nunca presentes una característica de `awk` solo porque existe.

Cada elemento del lenguaje debe aparecer después de que el estudiante haya encontrado una limitación concreta que lo haga necesario.

# 4. Cambio conceptual

S22 no trata sobre aprender `awk`.

S22 trata sobre pasar de:

```text
seleccionar y contar registros
```

a:

```text
expresar condiciones sobre varios campos
+
calcular medidas derivadas
+
resumir conjuntos de registros
```

Hasta ahora, muchas preguntas podían resolverse encadenando:

```text
grep → cut → sort → uniq → wc
```

Pero las nuevas preguntas requieren simultáneamente:

* seleccionar un tipo de registro;
* consultar una cadena;
* reconocer un replicón;
* operar con las coordenadas inicial y final;
* acumular valores;
* producir una salida estructurada.

Las tuberías anteriores se vuelven:

* largas;
* difíciles de leer;
* frágiles ante cambios;
* incapaces de realizar ciertos cálculos.

`awk` aparece únicamente porque permite expresar estas operaciones en una forma más directa y legible.

# 8. Herramienta nueva: alcance permitido de `awk`

Introduce únicamente lo necesario para responder las preguntas de la sesión.

## Elementos esenciales

* `awk 'condición { acción }' archivo`
* `-F '\t'` o `BEGIN { FS="\t" }`
* campos `$1`, `$2`, …, `$NF`;
* `NR` y `NF`, únicamente si resuelven una necesidad real;
* comparación numérica y textual;
* condiciones con `&&` y `||`;
* `print`;
* aritmética con campos;
* variables internas de `awk` para:

  * contar;
  * acumular;
  * conservar mínimo y máximo;
* bloque `BEGIN`, solo si es necesario para definir separadores o encabezados;
* bloque `END`, cuando el cálculo requiera emitir un resumen final;
* `printf`, únicamente para dar una salida tabular legible o controlar decimales.

## Límites

No introduzcas en S22:

* variables de shell;
* parámetros de línea de comandos con `-v`, salvo que el plan aprobado lo exija;
* funciones definidas por el usuario;
* ciclos externos;
* scripts extensos de `awk`;
* archivos `.awk`;
* procesamiento de múltiples archivos con lógica compleja;
* programación avanzada;
* abstracciones que pertenecen a cursos posteriores.

## Sobre variables internas

Sí pueden utilizarse variables dentro de `awk`, porque son necesarias para contar, sumar y calcular promedios.

Debes introducirlas como **acumuladores con significado biológico**, no como un tema de programación.

Por ejemplo:

```text
genes = número de genes observados
suma = longitud acumulada
min = longitud mínima observada
max = longitud máxima observada
```

No enseñar “variables” de forma abstracta.

# 26. Criterio final de calidad

La sesión final debe permitir que un estudiante responda:

* ¿por qué `grep` y `cut` dejaron de ser suficientes?
* ¿qué columnas requiere mi pregunta?
* ¿qué condición expresa exactamente?
* ¿qué cálculo debo realizar?
* ¿por qué la longitud es `fin - inicio + 1`?
* ¿cómo verifico mínimo, máximo y media?
* ¿qué diferencia hay entre número de genes y densidad?
* ¿qué respuesta final obtuve para el tamaño del genoma?
* ¿cómo cambia mi interpretación de las discrepancias de S21 al medirlas?
* ¿por qué una solución con `awk` puede ser más clara, pero no necesariamente siempre mejor?
* ¿qué impide todavía ejecutar todo el análisis de principio a fin automáticamente?

La sesión debe consolidar esta narrativa:

```text
S18  Seleccionar
↓
S19  Identificar
↓
S20  Normalizar
↓
S21  Confrontar
↓
S22  Condicionar y calcular
↓
S23  Integrar y ejecutar
```

No hagas un tutorial de `awk`.

Construye una sesión sobre cómo **formular y medir preguntas biológicas complejas a partir de datos tabulares**.
